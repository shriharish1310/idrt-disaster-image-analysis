# CV tailoring checklist

Add or emphasize the following before sending the application. Do not claim an item unless it is accurate.

- Current MS/PhD program, department, Texas A&M affiliation, expected graduation, and GPA if strong.
- Image analytics coursework: computer vision, deep learning, remote sensing, GIS, image processing, or machine learning.
- Python, PyTorch/TensorFlow, OpenCV, NumPy/Pandas, Git/GitHub, geospatial tools, and cloud/HPC experience.
- Two or three relevant projects with quantified outcomes, dataset sizes, models, validation methods, and your specific contribution.
- Publications, posters, conference submissions, research assistantships, or reproducible open-source work.
- A new project entry for this submission, for example:

  **Disaster Image Similarity and Change Screening | Python, PyTorch, DINOv2, OpenCV**  
  Built a reproducible multi-sensor comparison pipeline for three disaster-imagery pairs; combined masked SSIM, error/edge metrics, tile-level DINOv2 embeddings, registration diagnostics, cloud-aware quality control, and spatial change visualizations; documented limitations and a validation plan.

- GitHub link: https://github.com/shriharish1310/idrt-disaster-image-analysis
- Remove unrelated detail so the final CV is ideally one page for an MS applicant or two pages for a PhD applicant with publications.
