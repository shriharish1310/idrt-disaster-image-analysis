# IDRT Disaster Image Analysis

Reproducible comparison of three before/after (or sequential post-event) satellite-image pairs supplied for the Institute for a Disaster Resilient Texas research opportunity.

The project combines image registration, pixel/structural similarity, perceptual embeddings, and spatial change maps. Raw imagery is deliberately excluded from Git; place the six supplied PNG files in `data/raw/` before running the pipeline.

## Repository status

Analysis implementation and results are in progress. The completed repository will include:

- a command-line analysis pipeline;
- pair-level quantitative metrics;
- publication-ready comparison figures;
- a concise methods and interpretation report;
- tests for image pairing and metric calculations.

## Data policy

The source imagery is not redistributed by this repository. Generated summaries and figures should be reviewed against the provider's terms before public release.
